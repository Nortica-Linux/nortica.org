# Nortica v1.0.0

The first release under the **Nortica** name, formerly DebianZFS.

- Debian-based live image and guided ZFS installation.
- Optional Hyprland + Noctalia desktop with Gruvbox styling.
- Shared dotfiles and desktop setup in the separate config repository.
- New project home under the **Nortica-Linux** GitHub organization.

[Download release assets](https://github.com/Nortica-Linux/nortica/releases/tag/v1.0.0){ .md-button .md-button--primary }
[Install Nortica](../getting-started/index.md){ .md-button }

The image is split into `.iso.part.*` assets. Download every part plus the matching checksum and follow the release's `REASSEMBLE.txt` before flashing it.

The [upstream release page](https://github.com/Nortica-Linux/nortica/releases/tag/v1.0.0) and [commit history](https://github.com/Nortica-Linux/nortica/commits/v1.0.0) are the source of truth for the release contents.
