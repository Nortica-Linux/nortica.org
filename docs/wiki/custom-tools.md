# Custom Tools

## zfs-autosnap
Automatically creates snapshots for you to browse and use.
For documentation on how to use it, see [ZFS snapshots](zfs.md#snapshots).

## This Wiki!
Just search your applications for "help" and you should see an entry callen "Nortica Help".
This will open this very wikipage :)

## Tickets!
Just search your applications for "ticket" and you should see an entry called "Create new ticket".
This way you can easily add issues or helptickets for me to help you with on GitHub.
Answers might even make it into this wiki :)
