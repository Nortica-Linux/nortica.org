# Custom tools

## zfs-autosnap

Automatically creates snapshots for you to browse and use. See [ZFS snapshots](zfs.md#snapshots) for the snapshot workflow.

## Nortica Install

Open **Nortica Install** from the live desktop's launcher or run `nortica-install`. The [installation guide](../getting-started/index.md) covers requirements, verification and the disk-erasure warning.

## Help and support

Search the launcher for **Nortica Help** to open the upstream installation walkthrough, or visit [docs.nortica.org](https://docs.nortica.org) for this wiki.

**Nortica Ticket** opens the [system issue tracker](https://github.com/Nortica-Linux/nortica/issues). Use [documentation issues](https://github.com/Nortica-Linux/nortica.org/issues) for corrections to this website, or [config issues](https://github.com/Nortica-Linux/config/issues) for dotfile and desktop-configuration problems.

When reporting a problem, include the release, hardware or VM details, failed step and relevant log excerpts. **Remove passwords, tokens, encryption keys and other private information before posting anything publicly.**
